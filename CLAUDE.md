# Mariana Engine (WebGPU)

C++20 game engine + ImGui editor on WebGPU (Google Dawn). One codebase builds native (Windows/MSVC primary) and web (Emscripten → `index.html`, deployed to GitHub Pages from branch `2025`). Author: Noel Pellkvist.

## Build

- Native: `cmake -B build` then `cmake --build build --config Debug --target app -j4` (VS Code task "build Debug"). Output `build/Debug/app.exe`.
- Web: `emcmake cmake -B build-web` then `cmake --build build-web -j4`. Uses `shell_modern.html`, ASYNCIFY, GLFW3, `--preload-file resources`, `FLECS_NO_THREADS`.
- CI: `.github/workflows/pages.yml` (emsdk 4.0.16) builds web and deploys Pages. No tests exist.
- Sources are picked up by `GLOB_RECURSE source/*.cpp` — new .cpp files need a CMake re-configure (CONFIGURE_DEPENDS handles it on build).
- `RESOURCE_DIR` is a compile definition = absolute path to `resources/`. All asset paths are given as `"/Shaders/x.wgsl"` and prefixed with it (`FileReader`, `Texture::LoadTexture`).

## Architecture

Entry: `source/main.cpp` → `EditorApp("Mariana Engine Editor").Start()`.

- **Globals** (`source/Init.{hpp,cpp}`): `instance`, `adapter`, `device`, `surface`, `windowFormat`, `deviceLimits`. `Init()` creates them synchronously via `WaitAny`. Include `"Init.hpp"` from .cpp files only.
- **Pimpl everywhere**: public headers avoid `webgpu_cpp.h`; GPU handles live in `struct Impl` and are returned as `void*` (`GetTextureView()`, `GetBuffer()`, `GetPipeline()`), cast back to `wgpu::*` in .cpp.
- **Application** (`Application.{hpp,cpp}`): owns `Window`, `IInput`, `ICamera* cam`, `GUI`. Loop: `OnUpdate` → cam update → `gui.PreUpdateGUI` → `OnGUI` → `OnRender` → `input.Update`. Native loop presents + `ProcessEvents`; web uses `emscripten_set_main_loop_arg`.
- **Window**: GLFW, sRGB surface format preferred, Fifo present, resize callback, F11 fullscreen.
- **GUI**: ImGui GLFW + WGPU backends, docking over viewport, custom "Mariana" style, JetBrainsMono Nerd Font.

### ECS (`ECS.hpp/.cpp`, `Prefab.*`)
Opaque wrapper over flecs; headers never include flecs.
- `Scene` (owns `flecs::world`), `Entity` (Scene* + uint64 id), `System` (flecs query + type-erased callback via `CreateSystem<Comps...>(fn(Entity, Comps&..., float dt))`; run manually with `.Run()`).
- Components must be registered by name: `ECS::RegisterComponent<T>("Name")` / `ECS::RegisterTag<T>("Name")` then `scene.UpdateComponentRegistry()`. Names matter — prefab cloning and the inspector look components up by name.
- Built-ins: `NameComponent`, `LocalTRS` (pos, quat xyzw, scale, `version`), `WorldXform` (model[16], normal[9], `id`, `version`), `XformCache`, `TransformClock`. A flecs system (`cascade` on the parent term, so parents always update before children; the parent's WorldXform/XformCache arrive as query terms) recomputes `WorldXform` and bumps `WorldXform.version` when `LocalTRS.version` or the parent changes. Mutate via `SetPosition/SetRotationQuat/SetScale` (they bump the version only if the value changed), or write `LocalTRS` and `++version` yourself.
- Typed access (`Has/Get/TryGet/Add`) goes through `ECS::detail::TypeSlot<T>()`, a per-type index into `Scene::Impl::slot_ids`, so it never hashes `type_info`. System queries are cached (`EcsQueryCacheAuto`) and walk field arrays per table. `ForEachRoot` uses a cached `!ChildOf` query.
- `WorldXform.id` is a per-scene monotonically increasing slot index into the GPU transform storage array.
- Hierarchy = flecs `ChildOf`. `Prefab` owns its own `Scene`; `Scene::Instantiate(prefab)` deep-clones by component name (skips WorldXform/cache/clock).

### Rendering
- `Renderer` holds ordered `Renderpass*`; the **last** pass renders into the swapchain (attachment 0), then ImGui is drawn in a separate Load pass with no depth attachment. Disabled passes (`SetEnabled(false)`) are skipped and keep their previous contents.
- `Renderpass(msaa, depth, outputFormats, w, h)` owns render targets + Depth24Plus. Draws come from its `renderSystem` (an ECS System) and/or `recordCallback`, via `SetShader2(shader, variant = ShaderVariant::Default) / SetMesh / SetMaterial2 / Draw(indexCount, startIndex, firstInstance, instanceCount = 1)`. Redundant pipeline/mesh/material binds are skipped (switching only the variant keeps the bound groups); the shader's non-material groups are bound once per shader switch.
- `Shader2` builder: `.Group(i).AddBuffer/AddTexture/AddSampler(name, binding, ...)`, `.SetMaterialGroup(i)`, `.SetVertexStructLayout`, `.SetWGSL`, `.SetRenderpass`, `.Build(shadow)`. Pipeline hardcodes: entry points `vertexMain`/`fragmentMain`, front face CW, back-cull (none for shadow), depth LessEqual Depth24Plus, sample count 1. Without `SetVertexStructLayout` the pipeline takes no vertex buffers and no culling (fullscreen passes; draw with `Renderpass::DrawFullscreen()`), and a renderpass without depth gets no depth state. `.SetDrawVariants(true)` also builds the other `ShaderVariant` pipelines on the same layout (`Renderpass.hpp`: `DoubleSided` = no culling, `Mirrored` = front-face culling for negative-determinant transforms, `Lines`, `Points`); `.SetDepthOnlyFragment(true)` keeps the fragment stage in a pass without color outputs (alpha-tested shadows). Samplers: `SamplerType_Repeat` (default; linear mag, nearest min, linear mips), `SamplerType_Comparison`, `SamplerType_LinearClamp` (linear everything, clamped).
- `Material2`: copies the shader's material bind group layout, `.SetTexture(name, tex)`, optional `.SetSampler(name, SamplerSettings)` (per-material address/filter/mip settings overriding the sampler's type), `.Build()`.
- `Buffer` + layouts (`UniformLayout.hpp`, `StorageBufferLayout.hpp`): layouts are built reflectively from a sample object + member refs and pack to WGSL alignment (vec3→16, mat columns stride 16). `StorageArrayLayout(count, obj, fields...)` for `array<T>`; `Buffer::Write(obj, index)`. Dynamic uniform buffers allocate stride*1024.
- `VertexBufferLayout{v, v.field...}` builds the vertex layout from a struct (`GLTF::Vertex`: pos, normal, tangent, uv0, uv1, color, boneIndices(uvec4), boneWeights).
- `StandardPBRPipeline` (`StandardPBR.*`): owns UBO (lightDir, cascades, `sunColor`, `skySH[9]`, `skyParams`), camera UBO, and storage arrays (131072 elems) for transforms, materials, bones, draw data. Transforms are staged with `QueueTransform` and sent by `FlushTransforms` in a few writes (runs of nearby slots).
- `Texture`: `TextureFormat` enum mirrors `wgpu::TextureFormat` values (cast directly). Load/Upload/Rescale (bilinear, CPU)/Cube/RenderTexture/Depth; `CreateTexture(..., mipLevels)` + `UploadTextureWithMips` (CPU box-filtered chain, any array layer); `CreateCubeTexture(faces, size, format)` uploads 6 faces with full mip chains (`LoadCubeTexture` loads files then calls it). `RequestPixelReadback(x,y)` / `TryGetPixelReadback(value)` = one async 1x1 readback in flight.
- `IMesh`: `VertexCount()/IndexCount()` are what was uploaded; object-space `boundsMin/boundsMax` are computed by `BuildMesh` when the vertex has `.position`, plus `jointBounds` (bind-pose `Bounds` of the vertices each joint influences, indexed like `boneIndices`) when it also has bone indices/weights. The glTF loader frees the CPU arrays after upload, uses 16-bit indices for meshes with <= 65536 vertices, and generates tangents (`GenerateTangents`, Lengyel's method, w so the bitangent points up the texture as glTF expects) for triangle primitives without TANGENT. `Submesh::topology` is `Triangles`, `Lines` or `Points`.

### Editor (`source/Editor/`)
- `EditorApp`: `shadowpasses` (one depth-only `Renderpass` per shadow cascade, `ShadowMapShader`, entities with `ShadowCasterTag`) then `renderpass` (outputs linear HDR `RGBA16Float` + `RGBA16Uint` pick target), then `postProcess` (`PostProcessPipeline`, `PostProcess.hpp`): 6-level bloom (13-tap downsample with Karis average and soft-knee threshold on the first level, 3x3 tent upsample chain), and a composite pass (bloom added on top, exposure, ACES, sRGB encode) that is the last pass, i.e. the swapchain. Settings live on `postProcess` and in the `Post Processing` editor window; the composite reads its per-pass constants from a dynamic `PostParams` uniform (one slot per pass). Shaders are file-level globals in `EditorApp.cpp`: `StandardPBRShader` (test.wgsl), `StandardSkyboxShader` (skybox.wgsl), `ShadowMapShader` (shadow.wgsl).
- Frame: `OnUpdate` runs animation and requests a pick on click. `OnRender` runs `scene.Update` once, uploads the camera, uploads only transforms whose `WorldXform.version` changed, uploads dirty materials, then `BuildDrawLists()`: frustum-cull (mesh bounds vs camera/light frustum), sort by (material, mesh, submesh), and turn each run into one instanced draw whose instances read consecutive `DrawData` entries (`frameDraws`, uploaded in one write). The skybox is drawn last. Shadow casters are drawn whole-mesh, instanced per mesh, per cascade.
- Shadows: cascaded shadow maps (`kShadowCascades` = 4 maps of `kShadowMapSize` = 2048², out to `kShadowDistance` = 80, constants in `StandardPBR.hpp`). `UpdateShadowCascades()` splits the view (75% log / 25% uniform), fits each slice with a rotation-invariant sphere, snaps it to whole texels (no shimmering), and writes `UBO.cascadeVP/cascadeSplits/cascadeTexel` plus each cascade's matrix into the dynamic uniform `shadowCascadeBuffer` (`SetBufferIndex("ShadowCascade", c)` in the cascade's pass). Each cascade culls casters against its own light volume and is skipped while its matrix and casters are unchanged (set `shadowsDirty` if the light moves). Points and lines cast no shadows. Casters are drawn whole (one index range, no fragment stage) except alpha-tested submeshes (material `alphaCutoff > 0`): those are drawn separately with `ShadowMapMaskedShader` (same `shadow.wgsl` plus a discarding fragment stage; its group 1 matches the PBR material group, so material bind groups are reused), and the opaque remainder of such a mesh is merged into contiguous index ranges. The shadow pipelines use slope-scaled depth bias (`Shader2::Build(true)`); receivers use a normal offset, 16-tap filtered PCF, blending between cascades, and a fade at the shadow distance.
- Picking: fragment writes 64-bit entity id as 4×u16 into target 1; a click requests a readback and the result selects the entity a frame or two later. Gizmo via ImGuizmo (keys 1/2/3 = T/R/S), Delete destroys selection.
- Camera: `EditorCameraController` (Unity-like: RMB look + WASD/Space/Shift, MMB pan), LH perspective ZO. Its aspect follows the window (`SetViewportSize` at startup, in `OnWindowResized` and on F11).
- Windows derive from `EditorWindow` (name, open flag, `Draw()`), stored in `EditorApp::EditorWindows` map: `Stats`, `Assets` (file browser over `RESOURCE_DIR`, thumbnails, drags `MARIANA_ASSET_GLTF` payload), `Hierarchy` (tree + glTF drop → spawn prefab), `Inspector` (drawers keyed by component name: `LocalTRS`, `MeshComponent`, `AnimationPlayer`; lists other components/tags).
- `GLTFLoader` is registered as the `AssetManager2` loader for `.gltf/.glb` (`assets.Load<Prefab>(path)`). Accessors: `ReadAccessor<T>` handles strides, normalized integers, sparse substitutions and accessors without a buffer view (zeros); `ReadAccessor<glm::mat4>` reads inverse bind matrices. Primitives: strips, fans and loops become lists (`ToListTopology`); triangle primitives without NORMAL get flat normals (de-indexed, given tangents ignored). Node matrices with a negative determinant decompose to a negative x scale. Each material texture gets its glTF sampler (wrap, filters; no sampler = repeat + trilinear) and UV set (TEXCOORD_0/1; higher sets warn). It registers textures (per image *and* color space: base color/emissive sRGB, others linear), materials, meshes and animations as sub-assets keyed `<file>#<kind>/<index>`, so a reload reuses what is still loaded. Prefab layout: a wrapper root (gets `AnimationPlayer` if animated) → glTF scene nodes; each node gets `AnimationTargetEntity{nodeIndex}`, mesh nodes get `MeshComponent{mesh, materials}` + `ShadowCasterTag`.
- Animation: `Animation` (channels of keyframes; T/R/S, step/linear/cubic). `AnimationPlayer` holds `AssetHandle<Animation> clips`, autoplays clip 0, and poses its entity + descendants (stopping at nested players) from `animationSystem.Run(dt)`.
- Skinning (GPU): glTF skins load as `Skin` assets (joint node indices + inverse bind matrices, `include/Skin.hpp`); skinned nodes get `SkinComponent`, whose joints are resolved by node index from the model's wrapper root (`ResolveJoints` in `EditorApp.cpp`). Each frame `skinningSystem` writes `inverse(meshWorld) * jointWorld * inverseBind` per joint into `frameBones` (one `boneBuffer` write; `BoneData` is just the matrix, normals use its 3x3) and sets `SkinComponent::boneOffset`; draws carry it in `DrawData::boneOffset` (`~0u` = not skinned). It also moves each of the mesh's `jointBounds` by `jointWorld * inverseBind` into `SkinComponent::bounds` (world space, exact for linear blend skinning), which the camera and every shadow cascade cull against (empty bounds = never culled). The pose version feeds the shadow cache. The skinned mesh node's own transform is effectively ignored, per the glTF spec.
- The Assets browser caches each folder listing (rescans on navigation or every ~1 s) and loads thumbnails lazily, one per frame.
- Lighting: `EditorApp::lighting` (`LightingSettings` in `StandardPBR.hpp`: sun azimuth/elevation/color/intensity, sky diffuse and reflection intensity) is turned into the UBO by `ApplyLighting()` each frame (a sun direction change sets `shadowsDirty`); the UBO is written once per frame when `uboDirty`. The skybox cubemap is loaded in the constructor via `CreateCubeTexture` (mips for blurry reflections) and `ComputeSkyIrradianceSH` (`SkyLight.hpp`: L2 spherical harmonics of the sky, cosine-convolved and divided by pi) fills `ubo.skySH`. Each draw picks a `ShaderVariant` (`DrawVariant()`: lines/points by submesh topology, else `DoubleSided` for `MaterialAsset::doubleSided`, else `Mirrored` when the world transform's determinant is negative); draws sort by variant first.
- Extra editor windows: `Loaded Assets` (`LoadedAssetsWindow`, closed by default, Window menu) lists every asset with status/ref count and has "Unload Unused". `Lighting` (`LightingWindow`, closed by default) edits `lighting`. Deleting an entity also calls `assets.UnloadUnused()`.

### Assets (`include/AssetsSystem/`, `source/AssetsSystem/`)
- `AssetManager2` is owned by `Application` (`assets` member, declared in the base so it outlives the scene). Per-type `AssetStorage<T>` of `shared_ptr<T>`; `AssetMetadata` per UUID `AssetID` (name, type, `path` = reloadable file, `key` = unique lookup key, status, refCount, persistent).
- `AssetHandle<T>` is ref-counted and caches the asset (`Get()` returns `const std::shared_ptr<T>&`, no lookup); components hold handles (`MeshComponent`, `AnimationPlayer`, `MaterialAsset::textures`). Include `AssetsSystem/AssetManager.hpp` (not just `AssetHandle.hpp`) wherever handles are copied or resolved.
- API: `RegisterLoader<T>(type, exts, fn)`, `Load<T>(path)` (dedupes by key), `LoadAsset<T>(id)`, `RegisterAsset<T>(ptr, type, name, key)` for in-memory/sub-assets, `Find<T>(key)`, `ForEach<T>`, `UnloadUnused()` (cascades until stable), `SetPersistent`.
- Asset types in use: `Texture`, `IMesh`, `Skin`, `MaterialAsset` (`include/MaterialAsset.hpp`: `Material2` bind group + `GLTFMaterialProperties` + texture handles + a GPU slot in the materials storage buffer, uploaded when dirty via `StandardPBRPipeline::UploadDirtyMaterials`), `Animation`, `Prefab`.
- `BuiltinAssets` (persistent): white sRGB/linear textures, flat normal, default material (`builtin://...` keys).
- `Submesh::materialIndex` = index into `MeshComponent::materials` (the glTF primitive index).

### Shaders (`resources/Shaders/`)
`test.wgsl` = live PBR shader (GGX, shadow PCF; group 0 = UBO/camera/DrawInfo/ModelData/Material/Bones/shadow maps 0-3 (bindings 6-9) + comparison sampler (10) + sky cubemap (11) + its sampler (12), group 1 = albedo 0, normal 1, metallicRoughness 2, occlusion 3, emissive 4, then one sampler per texture at 5-9 (`albedoSampler` ... `emissiveSampler`), matching the `Material2::SetTexture/SetSampler` names). Each texture reads `uv` or `uv1` by bit in `MaterialProperties.uvSets`; COLOR_0 multiplies base color and alpha; the vertex shader passes `mirror` (-1 for a negative determinant), which flips the face side and the bitangent; fragments with no normal (points/lines without NORMAL) are drawn unlit. Lighting = sun (`UBO.sunColor`, full-strength shadows) + sky: diffuse from `skyIrradiance(N)` (the SH) and reflections from `skyReflection()` (cubemap mip picked from roughness, fading to the SH when very rough) weighted by `envBRDFApprox` (Karis' analytic split-sum fit), both times AO. Normals: the interpolated tangent frame is re-orthonormalized per pixel and bent by the normal map (xy scaled by `normalMapStrength`); back faces (double-sided only) flip the whole frame via `front_facing`; the shadow lookup offset uses the geometric normal. Both the PBR and shadow shaders read their per-instance data from `DrawInfo[instance_index]` (`transformIndex`, `materialIndex`, `boneOffset`) and skin vertices with `skinMatrix()` (blend of up to 4 `Bones[boneOffset + joint]` matrices, identity when `boneOffset == NO_SKIN`). `skybox.wgsl` live (samples mip 0 only; writes the cubemap pre-inverted through ACES and `camInfo.exposure`, so it reaches the screen as authored, and alpha 0 so it never blooms). `bloom_down.wgsl`, `bloom_up.wgsl`, `composite.wgsl` are the post-processing passes. `outline.wgsl`, `test_old.wgsl` are legacy. WGSL struct layouts must match the C++ structs in `StandardPBR.hpp` / `ICamera.hpp` / `MaterialAsset.hpp`.
- Color: the scene renders linear HDR; only `composite.wgsl` tonemaps and encodes with `linearToSrgb`, because the swapchain is deliberately UNORM (`Window::GetSurface`). Color textures are sRGB formats (decoded on sample). `CameraInfo.exposure` is set from `postProcess.exposure` each frame. Emissive can exceed 1 (glTF `KHR_materials_emissive_strength`, or the HDR Emissive control per material in the Mesh inspector). ImGui textures (asset thumbnails) are UNORM.

## Known quirks
- `FileReader::LoadRawString` logs and throws `std::runtime_error` on a missing file.
- File/Edit/Help menu items are TODO placeholders; `Application::Quit()` is declared but not defined.
- `WorldXform.id` slots are never reused, and `Buffer::Write` throws past 131072 transforms.
- `imgui.ini` is tracked in git and changes whenever the layout does.
- `resources/Models/Sponza/` (Khronos glTF-Sample-Assets Sponza, 51 MB, `.gltf` + external textures) is untracked; the web build preloads all of `resources/`, so it makes `index.data` ~100 MB. It has 3 alpha-masked, double-sided materials (ivy, flowers, chains), handy for testing those paths; the arcades get only sky light, so they stay darker than the courtyard.
