# Mariana Engine (WebGPU)

C++20 game engine + ImGui editor on WebGPU (Google Dawn). One codebase builds native (Windows/MSVC primary) and web (Emscripten → `index.html`, deployed to GitHub Pages from branch `2025`). Author: Noel Pellkvist.

## Build

- Native: `cmake -B build` then `cmake --build build --config Debug --target app -j4` (VS Code task "build Debug"). Output `build/Debug/app.exe`.
- Web: `emcmake cmake -B build-web` then `cmake --build build-web -j4`. Uses `shell_modern.html`, ASYNCIFY, GLFW3, `--preload-file resources`, `FLECS_NO_THREADS`.
- CI: `.github/workflows/pages.yml` (emsdk 4.0.16) builds web and deploys Pages. No tests exist.
- Sources are picked up by `GLOB_RECURSE source/*.cpp` — new .cpp files need a CMake re-configure (CONFIGURE_DEPENDS handles it on build).
- `RESOURCE_DIR` is a compile definition = absolute path to `resources/`. All asset paths are given as `"/Shaders/x.wgsl"` and prefixed with it (`FileReader`, `Texture::LoadTexture`).

## Architecture

Entry: `source/main.cpp` → `EditorApp().Start()`.

- **Globals** (`source/Init.{hpp,cpp}`): `instance`, `adapter`, `device`, `surface`, `windowFormat`, `deviceLimits`. `Init()` creates them synchronously via `WaitAny`. Include `"Init.hpp"` from .cpp files only.
- **Pimpl everywhere**: public headers avoid `webgpu_cpp.h`; GPU handles live in `struct Impl` and are returned as `void*` (`GetTextureView()`, `GetBuffer()`, `GetPipeline()`), cast back to `wgpu::*` in .cpp. The exception is `NativeGPU.hpp` (`NativeGPU::Device()`, `SurfaceFormat()`), for code outside the engine that talks to WebGPU itself (the ImGui backend).
- **Application** (`Application.{hpp,cpp}`): the app base class. Its constructor takes the app's `WindowSettings` (title, size, icon; the engine has no defaults). Owns `Window`, `IInput`, `std::unique_ptr<ICamera> cam` (set by the app) and `assets`. Loop: `OnUpdate` → cam update → `OnGUI` → `OnRender` → `input.Update`. Native loop presents + `ProcessEvents`; web uses `emscripten_set_main_loop_arg`.
- **Window**: GLFW, sRGB surface format preferred, Fifo present, resize callback, F11 fullscreen.
- **GUI** (editor only, owned by `EditorApp`): ImGui GLFW + WGPU backends, docking over viewport, custom "Mariana" style, JetBrainsMono Nerd Font. `EditorApp` inits it in `OnStart`, starts the frame in `OnGUI` and draws it as the renderer's overlay.

### ECS (`ECS.hpp/.cpp`, `Prefab.*`)
Opaque wrapper over flecs; headers never include flecs.
- `Scene` (owns `flecs::world`), `Entity` (Scene* + uint64 id), `System` (flecs query + type-erased callback via `CreateSystem<Comps...>(fn(Entity, Comps&..., float dt))`; run manually with `.Run()`).
- Components must be registered by name: `ECS::RegisterComponent<T>("Name")` / `ECS::RegisterTag<T>("Name")` then `scene.UpdateComponentRegistry()`. Names matter — prefab cloning and the inspector look components up by name. The ECS's own components register themselves when a `Scene` is constructed (`ECS::RegisterBuiltinComponents`); modules provide `RegisterComponents()` for theirs (`AnimationPlayer::`, `SceneRenderer::`), which the app calls.
- Built-ins: `NameComponent`, `LocalTRS` (pos, quat xyzw, scale, `version`), `WorldXform` (model[16], normal[9], `id`, `version`), `XformCache`, `TransformClock`. A flecs system (`cascade` on the parent term, so parents always update before children; the parent's WorldXform/XformCache arrive as query terms) recomputes `WorldXform` and bumps `WorldXform.version` when `LocalTRS.version` or the parent changes. Mutate via `SetPosition/SetRotationQuat/SetScale` (they bump the version only if the value changed), or write `LocalTRS` and `++version` yourself.
- Typed access (`Has/Get/TryGet/Add`) goes through `ECS::detail::TypeSlot<T>()`, a per-type index into `Scene::Impl::slot_ids`, so it never hashes `type_info`. System queries are cached (`EcsQueryCacheAuto`) and walk field arrays per table. `ForEachRoot` uses a cached `!ChildOf` query.
- `WorldXform.id` is a per-scene monotonically increasing slot index into the GPU transform storage array.
- Hierarchy = flecs `ChildOf`. `Prefab` owns its own `Scene`; `Scene::Instantiate(prefab)` deep-clones by component name (skips WorldXform/cache/clock).

### Rendering (engine: `include/Rendering/`, `source/Rendering/`, on top of the GPU wrappers in `include/`)
- `Renderer` owns `RenderGraph graph`; `Render(overlay)` executes the graph (whatever writes "Backbuffer" ends up on screen), then calls the optional `Renderer::Overlay` with a pass that loads the backbuffer and has no depth (the editor draws ImGui there). Set the graph's backbuffer format and output size before adding passes that render to the screen.
- `RenderGraph` (`Rendering/RenderGraph.hpp`): named textures (`GraphTextureDesc`: format, `scale` of the output size or fixed `width`/`height`, `msaa`) and passes (`GraphPassDesc`: `colorTargets`, `resolveTargets`, `depthTarget`, `reads`, `keep`, `record(Renderpass&)`). `Compile()` orders passes topologically by what they read and write (insertion order otherwise; a later writer of a texture depends on earlier ones and loads instead of clearing), culls passes not needed for the backbuffer or a `keep` pass, creates every declared texture at its size (recreated on `SetOutputSize`), and calls the `OnTexturesChanged` callbacks after every compile so owners rebind. `SetFallback(name, tex)` = what readers get when nothing writes a name. Passes, textures and callbacks carry an owner; `RemoveOwner` removes a feature or effect. `AddPass` returns the pass's `Renderpass` immediately so shaders can be built against it; `Execute` recompiles when anything changed. Disabled passes (`Renderpass::SetEnabled(false)`) keep their previous contents.
- `Renderpass(msaa, depth, outputFormats, w, h)`: render graph passes get their textures through `SetTargets` (nullptr color = backbuffer) and `SetLoadOps`; standalone passes can still own targets (`Init`/`Recreate`). With `msaa` (`IsMSAA()`) the targets have 4 samples and resolve at the end of the pass into `GetRenderResloveTarget(i)` (the samples are discarded). Draws come from its `renderSystem` (an ECS System) and/or `recordCallback`, via `SetShader2(shader, variant = ShaderVariant::Default) / SetMesh / SetMaterial2 / Draw(indexCount, startIndex, firstInstance, instanceCount = 1)`. Redundant pipeline/mesh/material binds are skipped (switching only the variant keeps the bound groups); the shader's non-material groups are bound once per shader switch.
- `Shader2` builder: `.Group(i).AddBuffer/AddTexture/AddSampler(name, binding, ...)`, `.SetMaterialGroup(i)`, `.SetVertexStructLayout`, `.SetWGSL`, `.SetRenderpass`, `.Build(shadow)`. Pipeline hardcodes: entry points `vertexMain`/`fragmentMain`, front face CW, back-cull (none for shadow), depth LessEqual Depth24Plus, sample count from the renderpass (4 for MSAA passes, which also get the `AlphaToCoverage*` variants). `RebuildBindGroups()` recreates the shader's own groups after textures it reads were resized. Without `SetVertexStructLayout` the pipeline takes no vertex buffers and no culling (fullscreen passes; draw with `Renderpass::DrawFullscreen()`), and a renderpass without depth gets no depth state. `.SetDrawVariants(true)` also builds the other `ShaderVariant` pipelines on the same layout (`Renderpass.hpp`: `DoubleSided` = no culling, `Mirrored` = front-face culling for negative-determinant transforms, `Lines`, `Points`); `.SetDepthOnlyFragment(true)` keeps the fragment stage in a pass without color outputs (alpha-tested shadows). Samplers: `SamplerType_Repeat` (default; linear mag, nearest min, linear mips), `SamplerType_Comparison`, `SamplerType_LinearClamp` (linear everything, clamped). `BindTexture(name, tex)` re-points one of the shader's own texture bindings after Build (then `RebuildBindGroups()`).
- `Material2`: copies the shader's material bind group layout, `.SetTexture(name, tex)`, optional `.SetSampler(name, SamplerSettings)` (per-material address/filter/mip settings overriding the sampler's type), `.Build()`.
- `Buffer` + layouts (`UniformLayout.hpp`, `StorageBufferLayout.hpp`): layouts are built reflectively from a sample object + member refs and pack to WGSL alignment (vec3→16, mat columns stride 16). `StorageArrayLayout(count, obj, fields...)` for `array<T>`; `Buffer::Write(obj, index)`. Dynamic uniform buffers allocate stride*1024. `RawBufferLayout{size, type}` = a buffer packed by its user (written with `WriteRawBytes`), e.g. effect parameters.
- `VertexBufferLayout{v, v.field...}` builds the vertex layout from a struct. The standard renderer's vertex is `StandardVertex` (`include/Vertex.hpp`: position, normal, tangent, texcoord0/1, color0, boneIndices(uvec4), boneWeights).
- `StandardPBRPipeline` (`StandardPBR.*`): owns UBO (lightDir, cascades, `sunColor`, `skySH[9]`, `skyParams`), camera UBO, and storage arrays (131072 elems) for transforms, materials, bones, draw data. Transforms are staged with `QueueTransform` and sent by `FlushTransforms` in a few writes (runs of nearby slots).
- `Texture`: `TextureFormat` enum mirrors `wgpu::TextureFormat` values (cast directly). Load/Upload/Rescale (bilinear, CPU)/Cube/RenderTexture/Depth; `CreateTexture(..., mipLevels)` + `UploadTextureWithMips` (CPU box-filtered chain, any array layer); `CreateCubeTexture(faces, size, format)` uploads 6 faces with full mip chains (`LoadCubeTexture` loads files then calls it). `RequestPixelReadback(x,y)` / `TryGetPixelReadback(value)` = one async 1x1 readback in flight.
- `IMesh`: `VertexCount()/IndexCount()` are what was uploaded; object-space `boundsMin/boundsMax` are computed by `BuildMesh` when the vertex has `.position`, plus `jointBounds` (bind-pose `Bounds` of the vertices each joint influences, indexed like `boneIndices`) when it also has bone indices/weights. `Submesh::topology` is `Triangles`, `Lines` or `Points`.
- Geometry (`include/Geometry/`, `source/Geometry/`): meshes are built from `MeshSection`s (vertices, indices (empty = in order), `SourceTopology` incl. strips/fans/loops, `materialIndex`, `hasNormals`, `hasTangents`). `BuildMesh(sections)` converts each section to a list topology (`Geometry::ToListTopology`), gives triangle sections without normals flat normals (`GenerateFlatNormals`, de-indexed) and tangents where missing (`GenerateTangents`, Lengyel's method, w so the bitangent points up the texture as glTF expects), makes one submesh per section, uses 16-bit indices when <= 65536 vertices, uploads and frees the CPU arrays. `Primitives::Cube/Plane/Sphere` return sections (front faces outward, wound like glTF: the front is where cross(p1 - p0, p2 - p0) points); `BuiltinAssets::PrimitiveMesh(assets, BuiltinMesh::...)` shares built ones (`builtin://mesh/...`). Importers and procedural code both go through this.
- `SceneRenderer` (`Rendering/SceneRenderer.hpp`): renders a `Scene` from an `ICamera` into the graph. `RegisterComponents()` (MeshComponent, SkinComponent, ShadowCasterTag; the first and last are in `Rendering/Components.hpp`) before `UpdateComponentRegistry`; `Init(graph)` adds its textures and passes, compiles, loads the sky and builds its shaders (`pbrShader` = test.wgsl, `skyboxShader`, `shadowShader`/`shadowMaskedShader` = shadow.wgsl, `prepassShader`); `Prepare(camera)` once per frame uploads the camera, lighting, changed transforms, dirty materials and bones, builds material bind groups (`BuildMaterialBindGroups`: every material whose textures changed, against `pbrShader`'s material group, empty slots get white sRGB / flat normal / white linear) and builds the draw lists. `SetSettings(SceneRendererSettings)` changes `shadows`, `shadowDistance` and `shadowMapSize` at runtime (a new size re-adds the maps; the graph recreates them and `BindGraphTextures` rebinds). Graph textures: `ShadowMap0..3` (fixed `shadowMapSize`², Depth24Plus), `SceneDepth` + `SceneNormals` (RGB10A2, view space) + `EntityIds` (RGBA16Uint) from the "Prepass", `SceneColorMS`/`SceneDepthMS` (4x MSAA) resolved into `SceneColor` (RGBA16Float) by the "Forward" pass, which reads the shadow maps and `AmbientOcclusion` (R8, white 1x1 fallback when no effect writes it; test.wgsl clamps its `textureLoad`). The prepass is `keep` while `writeEntityIds` (editor picking). The sky is an inward-facing `Primitives::Cube` drawn last with skybox.wgsl.
- Frame (inside `Prepare`/`BuildDrawLists`): frustum-cull (mesh bounds vs camera/light frustum), sort by (variant, material, mesh, submesh), and turn each run into one instanced draw whose instances read consecutive `DrawData` entries (`frameDraws`, one write). Each draw picks a `ShaderVariant` (`DrawVariant()`: lines/points by topology, else `DoubleSided` for `MaterialAsset::doubleSided`, else `Mirrored` for a negative-determinant transform; alpha-tested materials use the `AlphaToCoverage*` variants). The prepass draws the same batches.
- Shadows: cascaded shadow maps (`kShadowCascades` = 4 maps, a constant in `StandardPBR.hpp`; size and distance from `SceneRendererSettings`, default 2048² out to 80 m). `UpdateShadowCascades()` splits the view (75% log / 25% uniform), fits each slice with a rotation-invariant sphere, snaps it to whole texels (no shimmering), and writes `UBO.cascadeVP/cascadeSplits/cascadeTexel` plus each cascade's matrix into the dynamic uniform `shadowCascadeBuffer` (`SetBufferIndex("ShadowCascade", c)` in the cascade's pass). Each cascade (graph pass "Shadow cascade c") culls casters against its own light volume and is skipped while its matrix and casters are unchanged (the light direction and alpha-tested materials' `Version()` are tracked, a cascade without casters ignores its matrix; `InvalidateShadows()` forces a redraw). With `shadows` off no casters are gathered, so the maps are cleared once and then skipped. Points and lines cast no shadows. Casters are drawn whole (one index range, no fragment stage) except alpha-tested submeshes (material `alphaCutoff > 0`): those are drawn separately with `ShadowMapMaskedShader` (same `shadow.wgsl` plus a discarding fragment stage; its group 1 matches the PBR material group, so material bind groups are reused), and the opaque remainder of such a mesh is merged into contiguous index ranges. The shadow pipelines use slope-scaled depth bias (`Shader2::Build(true)`); receivers use a normal offset, 16-tap filtered PCF, blending between cascades, and a fade at the shadow distance.
- Skinning (GPU): glTF skins load as `Skin` assets (joint node indices + inverse bind matrices, `include/Skin.hpp`); skinned nodes get `SkinComponent`, whose joints are resolved by node index from the model's wrapper root (`ResolveJoints` in `EditorApp.cpp`). Each frame `skinningSystem` writes `inverse(meshWorld) * jointWorld * inverseBind` per joint into `frameBones` (one `boneBuffer` write; `BoneData` is just the matrix, normals use its 3x3) and sets `SkinComponent::boneOffset`; draws carry it in `DrawData::boneOffset` (`~0u` = not skinned). It also moves each of the mesh's `jointBounds` by `jointWorld * inverseBind` into `SkinComponent::bounds` (world space, exact for linear blend skinning), which the camera and every shadow cascade cull against (empty bounds = never culled). The pose version feeds the shadow cache. The skinned mesh node's own transform is effectively ignored, per the glTF spec.
- Lighting: `SceneRenderer::lighting` (`LightingSettings` in `StandardPBR.hpp`: sun azimuth/elevation/color/intensity, sky diffuse and reflection intensity) is turned into the UBO each frame (a sun direction change redraws the shadows). The skybox cubemap is loaded in `Init` via `CreateCubeTexture` (mips for blurry reflections) and `ComputeSkyIrradianceSH` (`SkyLight.hpp`: L2 spherical harmonics of the sky, cosine-convolved and divided by pi) fills `ubo.skySH`. Each draw picks a `ShaderVariant` (`DrawVariant()`: lines/points by submesh topology, else `DoubleSided` for `MaterialAsset::doubleSided`, else `Mirrored` when the world transform's determinant is negative); draws sort by variant first.
- Effects (`Rendering/Effect.hpp`, files in `resources/Effects/*.effect`, shaders in `resources/Shaders/Effects/`): an effect file (JSON) declares `stage` ("BeforeLighting" writes scene textures the forward pass reads, e.g. GTAO writes `AmbientOcclusion`; "PostProcess" runs on the HDR image), `final` (writes the screen, always last: Tonemap), `parameters` (float/int/bool/vec2-4/color3-4 with default/min/max, packed in file order with WGSL layout into a uniform `params`), private `textures` (format, scale or size) and `passes` (shader, `inputs` binding name -> texture, `output`, per-pass `constants`). Names are private textures, `Input`/`Output` (the post chain) or any graph texture. Each pass shader only defines `fragmentMain(input: FullscreenInput)`; the effect system prepends `params`, `passInfo` (outputSize xy/zw, constants), `camera` (CameraInfo), `linearClamp`, the inputs (depth formats as `texture_depth_2d`) and the fullscreen vertex shader. `EffectStack` (owned by the app) loads effects (`Add(path)`), removes, moves within a stage, and rebuilds its part of the graph when effects are added, removed, moved or toggled (pipelines are kept when formats don't change); post effects chain through `PostColor<i>` textures from `SceneColor` to the backbuffer, and `Present.effect` is used when no final effect is enabled. Exposure is the camera's (`ICamera::SetExposure`), read by tonemap.wgsl and skybox.wgsl.
- Render pipelines as data (`Rendering/RenderPipeline.hpp`, files in `resources/Pipelines/*.pipeline`): `RenderPipelineDesc` = name, `exposure`, `scene` (`SceneRendererSettings`) and `effects` (effect file path, `enabled`, parameter values by name). `Load(path, desc, error)` / `Save(path, error)` (JSON, see the header; missing values keep defaults, unknown parameters warn on Apply), `Apply(effects, sceneRenderer, camera*)` (clears the stack and loads every effect file anew), `Capture(effects, sceneRenderer, camera*)` = what runs now. It is plain data, so code (and later scripts) can build, edit and apply one; custom shaders and bindings come in through effect files.

### Editor (`source/Editor/`)
- `EditorApp` owns `Renderer renderer` (declared first: the others remove their passes from its graph), `Scene scene`, `SceneRenderer sceneRenderer` and `EffectStack effects` (set up from `resources/Pipelines/Default.pipeline`: GTAO, Bloom, Tonemap, exposure 1.5); it only adds editor things: windows, picking, the gizmo, the animation system, prefab spawning. `OnRender` = `scene.Update`, `sceneRenderer.Prepare(*cam)`, `effects.Update()`, `renderer.Render(&gui)`; a resize only calls `renderer.graph.SetOutputSize`.
- Picking: the prepass writes (graph texture `EntityIds`) the 64-bit entity id as 4×u16 into its target 1 (0 = nothing drawn); a click requests a readback and the result selects the entity a frame or two later.
- Camera: `EditorCameraController` (Unity-like: RMB look + WASD/Space/Shift, MMB pan), LH perspective ZO. Its aspect follows the window (`SetViewportSize` at startup, in `OnWindowResized` and on F11).
- Windows derive from `EditorWindow` (name, open flag, `Draw()`), stored in `EditorApp::EditorWindows` map: `Stats`, `Assets` (file browser over `RESOURCE_DIR`, thumbnails, drags `MARIANA_ASSET_GLTF` and `MARIANA_ASSET_IMAGE` payloads (null-terminated path)), `Hierarchy` (tree + glTF drop → spawn prefab), `Inspector` (drawers keyed by component name: `LocalTRS`, `MeshComponent`, `AnimationPlayer`; lists other components/tags). The `MeshComponent` drawer is a full material editor per submesh: factors, emissive (HDR), alpha mode/cutoff, double sided, and per texture slot the texture (drop an image to load it through `ImageImporter` in the slot's color space; Clear), UV set and sampler settings. Edits change the material asset, so every mesh using it.
- The `Create` menu spawns a cube, sphere or plane (`SpawnPrimitive`: shared builtin mesh, a new material per entity, 5 m in front of the camera, selected).
- Importers (`include/Importers/`, `source/Importers/`, engine side): `GLTF::GLTFLoader::RegisterLoader(assets)` makes it the `AssetManager2` loader for `.gltf/.glb` (`assets.Load<Prefab>(path)`); it needs no renderer. Accessors: `ReadAccessor<T>` handles strides, normalized integers, sparse substitutions and accessors without a buffer view (zeros); `ReadAccessor<glm::mat4>` reads inverse bind matrices. Each primitive becomes a `MeshSection` (`LoadPrimitive`; mode -> `SourceTopology`, `hasNormals`/`hasTangents` from the attributes), a mesh = `BuildMesh` of its primitives. Node matrices with a negative determinant decompose to a negative x scale. Materials are plain `MaterialAsset`s: factors, `SetAlphaMode`, and `SetTexture(slot, texture, glTF sampler (no sampler = repeat + trilinear), UV set (TEXCOORD_0/1; higher sets warn))`; missing textures stay empty. It registers textures (per image *and* color space: base color/emissive sRGB, others linear), materials, meshes and animations as sub-assets keyed `<file>#<kind>/<index>`, so a reload reuses what is still loaded. `ImageImporter::LoadTexture(assets, file, srgb)` loads an image file as a mipmapped texture (keyed `<file>#srgb`/`#linear`). Prefab layout: a wrapper root (gets `AnimationPlayer` if animated) → glTF scene nodes; each node gets `AnimationTargetEntity{nodeIndex}`, mesh nodes get `MeshComponent{mesh, materials}` + `ShadowCasterTag`.
- Animation: `Animation` (channels of keyframes; T/R/S, step/linear/cubic). `AnimationPlayer` holds `AssetHandle<Animation> clips`, autoplays clip 0, and poses its entity + descendants (stopping at nested players) from `animationSystem.Run(dt)`.
- The Assets browser caches each folder listing (rescans on navigation or every ~1 s) and loads thumbnails lazily, one per frame.
- Extra editor windows: `Loaded Assets` (`LoadedAssetsWindow`, closed by default, Window menu) lists every asset with status/ref count and has "Unload Unused". `Lighting` (`LightingWindow`) edits `sceneRenderer.lighting`; `Render Pipeline` (`RenderPipelineWindow`): pipeline file combo (load from `resources/Pipelines`), Save / Reload / Save As, camera exposure, scene settings (shadows, distance, map size), then each effect with controls built from its parameter types/ranges, toggle, reorder, remove, and "Add effect" listing `resources/Effects`. Deleting an entity also calls `assets.UnloadUnused()`.

### Assets (`include/AssetsSystem/`, `source/AssetsSystem/`)
- `AssetManager2` is owned by `Application` (`assets` member, declared in the base so it outlives the scene). Per-type `AssetStorage<T>` of `shared_ptr<T>`; `AssetMetadata` per UUID `AssetID` (name, type, `path` = reloadable file, `key` = unique lookup key, status, refCount, persistent).
- `AssetHandle<T>` is ref-counted and caches the asset (`Get()` returns `const std::shared_ptr<T>&`, no lookup); components hold handles (`MeshComponent`, `AnimationPlayer`, a `MaterialAsset`'s texture slots). Include `AssetsSystem/AssetManager.hpp` (not just `AssetHandle.hpp`) wherever handles are copied or resolved.
- API: `RegisterLoader<T>(type, exts, fn)`, `Load<T>(path)` (dedupes by key), `LoadAsset<T>(id)`, `RegisterAsset<T>(ptr, type, name, key)` for in-memory/sub-assets, `Find<T>(key)`, `ForEach<T>`, `UnloadUnused()` (cascades until stable), `SetPersistent`.
- Asset types in use: `Texture`, `IMesh`, `Skin`, `MaterialAsset`, `Animation`, `Prefab`.
- `MaterialAsset` (`include/MaterialAsset.hpp`) is source-independent (importers, code, the editor make them the same way): `properties` (`PBRMaterialProperties`, mirrors `MaterialProperties` in the shaders; call `MarkDirty()` after changing it), `doubleSided`, `SetAlphaMode(Opaque/Mask/Blend, cutoff)` (writes `alphaCutoff`; Blend draws like Mask), `SetTexture(MaterialTexture::BaseColor/Normal/MetallicRoughness/Occlusion/Emissive, handle, SamplerSettings, uvSet)` (keeps `uvSets` in sync), `GetTexture(slot)`, `Version()` (bumped by every edit). The renderer owns the GPU side: `material` (the `Material2` bind group, rebuilt while `BindGroupDirty()`) and a slot in the materials storage buffer, uploaded when dirty via `StandardPBRPipeline::UploadDirtyMaterials`.
- `BuiltinAssets`: white sRGB/linear textures, flat normal, default material (no textures) (persistent), primitive meshes (`builtin://...` keys).
- `Submesh::materialIndex` = index into `MeshComponent::materials` (the glTF primitive index; a `MeshSection`'s `materialIndex`).

### Shaders (`resources/Shaders/`)
`test.wgsl` = live PBR shader (forward pass) (GGX, shadow PCF; group 0 = UBO/camera/DrawInfo/ModelData/Material/Bones/shadow maps 0-3 (bindings 6-9) + comparison sampler (10) + sky cubemap (11) + its sampler (12), group 1 = albedo 0, normal 1, metallicRoughness 2, occlusion 3, emissive 4, then one sampler per texture at 5-9 (`albedoSampler` ... `emissiveSampler`), matching the names `SceneRenderer::BuildMaterialBindGroups` binds). Each texture reads `uv` or `uv1` by bit in `MaterialProperties.uvSets`; COLOR_0 multiplies base color and alpha; the vertex shader passes `mirror` (-1 for a negative determinant), which flips the face side and the bitangent; fragments with no normal (points/lines without NORMAL) are drawn unlit. Lighting = sun (`UBO.sunColor`, full-strength shadows) + sky: diffuse from `skyIrradiance(N)` (the SH) and reflections from `skyReflection()` (cubemap mip picked from roughness, fading to the SH when very rough) weighted by `envBRDFApprox` (Karis' analytic split-sum fit), both times AO. Normals: the interpolated tangent frame is re-orthonormalized per pixel and bent by the normal map (xy scaled by `normalMapStrength`); back faces (double-sided only) flip the whole frame via `front_facing`; the shadow lookup offset uses the geometric normal. Both the PBR and shadow shaders read their per-instance data from `DrawInfo[instance_index]` (`transformIndex`, `materialIndex`, `boneOffset`) and skin vertices with `skinMatrix()` (blend of up to 4 `Bones[boneOffset + joint]` matrices, identity when `boneOffset == NO_SKIN`). `skybox.wgsl` live (samples mip 0 only; writes the cubemap pre-inverted through ACES and `camInfo.exposure`, so it reaches the screen as authored, and alpha 0 so it never blooms). `prepass.wgsl` (depth/normals/pick). Effect shaders live in `Shaders/Effects/` (gtao, gtao_blur, bloom_down/up/apply, tonemap, present). In test.wgsl, alpha-tested materials output coverage (alpha sharpened around the cutoff) for alpha to coverage, and the `AmbientOcclusion` graph texture (binding 13, `textureLoad` at the pixel, clamped so the 1x1 fallback works) is combined with the material AO by `min` and applied to sky light only, with `multiBounceAO` and `specularOcclusion`. `outline.wgsl`, `test_old.wgsl` are legacy. WGSL struct layouts must match the C++ structs in `StandardPBR.hpp` / `ICamera.hpp` / `MaterialAsset.hpp`.
- Color: the scene renders linear HDR; only the final effect (tonemap.wgsl, or present.wgsl) tonemaps and encodes with `linearToSrgb`, because the swapchain is deliberately UNORM (`Window::GetSurface`). Color textures are sRGB formats (decoded on sample). `CameraInfo.exposure` is the camera's exposure (`ICamera::SetExposure`; set by the pipeline, 1.5 in Default.pipeline). Emissive can exceed 1 (glTF `KHR_materials_emissive_strength`, or the HDR Emissive control per material in the Mesh inspector). ImGui textures (asset thumbnails) are UNORM.

## Known quirks
- `FileReader::LoadRawString` logs and throws `std::runtime_error` on a missing file.
- File/Edit/Help menu items are TODO placeholders; `Application::Quit()` is declared but not defined.
- The project is being split into `engine/` (static library MarianaEngine, includes as `<Mariana/...>`), `editor/` (MarianaEditor) and `runtime/` (MarianaPlayer); until that lands, everything still builds as the single `app` target.
- `WorldXform.id` slots are never reused, and `Buffer::Write` throws past 131072 transforms.
- `imgui.ini` is tracked in git and changes whenever the layout does.
